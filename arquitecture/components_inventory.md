# Components Inventory

- **Sidebar**
  - Purpose: Main application navigation.
  - Reusability: Global.
  - UI Importance: High.

- **KPI Card**
  - Purpose: Display high-level metrics (e.g., Total Hours, Headcount).
  - Reusability: High (Dashboard, Reports).
  - Data displayed: Number, label, icon, trend indicator.

- **Data Table (Matrix)**
  - Purpose: Render timeseries data with fixed left columns and scrolling right columns.
  - Reusability: Medium (Hours Report, Schedule Board).
  - UI Importance: Critical.

- **DrillDown Modal**
  - Purpose: Show detailed lists when clicking a KPI.
  - Reusability: High.

- **Date Range Editor / Quick Select**
  - Purpose: Standardized date picking.
  - Reusability: High across all analytics pages.
  - UI Importance: High.

- **Toggle Switch**
  - Purpose: Boolean settings (e.g., Active Only, Adjusted Hours).
  - Reusability: High.

- **Status Badges**
  - Purpose: Indicate employee states (Online, Offline, Late).
  - Reusability: High.
