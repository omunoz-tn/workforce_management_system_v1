# Roles & Permissions

## Admin
- **Description**: Full system access, manages configuration and users.
- **Permissions**: All modules, including Settings and User Management.
- **Accessible modules**: All.
- **Restricted sections**: None.
- **Typical workflows**: Creating new managers, adjusting system-wide report settings, auditing sync history.

## Manager
- **Description**: Oversees multiple teams or a whole department.
- **Permissions**: View dashboards, generate reports, manage team rosters.
- **Accessible modules**: Dashboard, Employees, Analytics, Scheduling.
- **Restricted sections**: Admin Settings, User Management.
- **Typical workflows**: Reviewing daily run rates, analyzing weekly hours, adjusting team assignments.

## Supervisor
- **Description**: Manages a specific team.
- **Permissions**: Restricted to assigned teams.
- **Accessible modules**: Dashboard (filtered), Reports (filtered), Schedule Board (filtered).
- **Restricted sections**: Cross-team analytics, Admin settings.
- **Typical workflows**: Checking intraday attendance, editing schedules for their team, tracking late arrivals.

## WFM Analyst
- **Description**: Responsible for forecasting and scheduling.
- **Permissions**: Full access to scheduling and analytics.
- **Accessible modules**: Scheduling, Analytics, Dashboard.
- **Restricted sections**: User management.
- **Typical workflows**: Generating forecasts, creating schedule templates, analyzing coverage gaps.
