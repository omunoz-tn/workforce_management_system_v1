# Pages Inventory

1. **Dashboard** (`/` or `currentView=dashboard`)
   - Purpose: Real-time overview.
   - Components: KPI Cards, DrillDownModal.
   - Charts: Gauge charts, bar charts (implied).

2. **All Employees** (`currentView=all-emp`)
   - Purpose: Raw data view of Desktime imports.
   - Components: Data Table, Pagination, Search.

3. **Teams** (`currentView=teams`)
   - Purpose: Org hierarchy management.
   - Components: Draggable lists, Modals for assignment.

4. **Hours Report View** (`currentView=report-hours`)
   - Purpose: Matrix report of daily hours.
   - Components: Matrix Table (sticky columns), DateRangeModal, Toggle Switch.

5. **Schedule Board** (`currentView=schedule-board`)
   - Purpose: Grid view of shifts.
   - Components: ScheduleGrid, ShiftEditor.

6. **Login Management** (`currentView=login-mgmt`)
   - Purpose: Admin user control.
   - Components: UserTable, RoleDropdowns.

7. **Reports Hub** (`currentView=reports`)
   - Purpose: Landing page for all available reports.
   - Components: Report Cards, Navigation Links.

8. **Sync History** (`currentView=report-sync-history`)
   - Purpose: View background data synchronization logs.
   - Components: Data Table, Status Badges.
